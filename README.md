# 🧠 Interaktiv Quizapplikation

En dynamisk och interaktiv webbapplikation där användaren kan göra quiz inom olika ämnen – allt hanteras på en enda HTML-sida med hjälp av JavaScript.

## 🎯 Syfte

- Dynamisk DOM-manipulation med JavaScript
- Strukturering av innehåll och flöde på en webbsida
- Användning av HTML, CSS och JavaScript i samspel
- Design och interaktion i responsiva gränssnitt

---

## 🧩 Funktioner

- 📃 **Startsida** med introduktion och val av quizkategori
- ✅ **Dynamiskt quizflöde** där frågor visas en i taget
- 🧠 **Två eller fler ämnen/kategorier** att välja mellan
- 🧮 **Poängräkning och resultatvisning** direkt på sidan
- 🎨 **Responsiv design** och enkla animationer/effekter

---

## 🚀 Så använder du appen

1. Öppna `index.html` i din webbläsare.
2. Läs introduktionen och välj ett ämne.
3. Svara på frågorna – en i taget.
4. Se ditt resultat direkt när quizen är klar.
